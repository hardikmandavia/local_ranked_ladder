# Legend portraits

Generated by `npm run portraits` from `assets/portraits/<Legend name>.png`
(resized to 192px JPEG, named by the slug in `src/data/legends.json`, e.g.
`master-yi-wuju-bladesman.jpg`). Edit the source in `assets/` and re-run
rather than editing these files. Legends without a file fall back to an
initials placeholder.
